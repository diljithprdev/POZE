Spec locked in — the bubble is the floating button; the tool bar sits in the same column directly under it and grows down out of the bubble's bottom edge, folding back up into it on close; opacity = inline vertical slider.
Bar: 56dp wide (same as the bubble), 44dp icon targets, 4dp gaps, 26dp hairline group divider, full radius. Order: Lock · Grid · Rotate · Opacity (+ inline vertical slider) ─ Gallery · Reset · Close · Stop. Gallery tint = accent-soft, Stop tint = red.
Open: pill and column translateY(-18dp) → 0 with opacity 0 → 1, 320ms decelerate — read as sliding down out from behind the bubble; icons translateY(-10dp) scale(.9) → 1, 240ms, 35ms stagger. If the bar ever has to flip above the bubble, both directions invert. Close: exact reverse, 150ms, no stagger. Slider: track 8dp × 112dp, fill from the bottom in accent, thumb 22×16dp radius 5dp (accent-soft + 2dp white), % readout 11sp dim; the bar only ever grows downward, so the bubble stays put and nothing is overlapped.
